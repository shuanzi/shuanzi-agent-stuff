# 翻译文章到 Everything Agent

## 固定约束

- 仅接受一个可访问的文章 URL；固定输出为简体中文。
- 固定归档父节点为 [Everything Agent](https://my.feishu.cn/wiki/LVtIwNHJ9it0Rkk3On9cb6GgnSd)，token 为 `LVtIwNHJ9it0Rkk3On9cb6GgnSd`。不要要求用户选择位置。
- 在操作飞书前，完整读取适用的 `lark-doc` 与 `lark-wiki` 技能的 `SKILL.md`，以及其中标为必读的全部引用；所有飞书命令均使用 `--as user`。
- 在 v1 中，遇到登录墙、付费墙、反爬限制或其他无法完整访问正文的页面时 fail closed：不要创建不完整文档，并说明无法访问的原因。

## 执行工作流

1. 获取并识别文章的主正文。排除站点导航、目录外推荐、广告、相关推荐、评论和其他非正文内容。
2. 在翻译前建立原文覆盖清单，记录原文标题、日期、作者、按顺序排列的章节与段落、每个列表项、表格、引语、全部正文链接（文本与目标 URL）以及语义图片（原图 URL、图注和 alt 文本）。将该清单作为后续对账的 source of truth。
3. 完整翻译主正文，不要总结、改写为提纲或静默省略。逐项对照原文覆盖清单，准确保留并翻译所有记录项；保留正文链接的目标 URL。准确处理技术术语、代码、产品名和专有名词，必要时保留原文。
4. 识别承载正文语义的图片，尽量下载或上传并插入飞书文档；排除纯装饰图。原图有 alt 文本但无图注时，将翻译后的 alt 文本写为图注或紧邻说明。无法取得或插入语义图片时，在对应位置写明中文降级说明，并保留原图链接或原文链接。
5. 在创建前使用 `wiki +node-get --as user` 核对固定父节点的 token、标题和可创建性。父节点不匹配、不可访问或无法确认时停止，不要创建文档。
6. 在固定父节点下创建新文档。将文档标题固定为“中文标题（全文翻译）”，其中“中文标题”是原文标题的完整中文翻译；明确传入 `--parent-token LVtIwNHJ9it0Rkk3On9cb6GgnSd`（并使用 `--as user`），不要覆盖或修改已有文档。
7. 在正文顶部依次写入原文标题、原文链接、发布日期和作者；原文未提供日期或作者时，明确写“原文未提供”，不要推断或虚构。随后写入完整译文。
8. 创建后使用 `docs +fetch --as user --doc <新文档 URL 或 token> --detail full` 完整回读；`full` 已包含 block IDs 和编辑元数据。将回读结果与原文覆盖清单逐项对账，确认标题、顶部元数据、章节与段落顺序、每个列表项、表格、引语、全部正文链接，以及每张语义图片或降级说明均已覆盖。发现缺项时修正并重新回读。
9. 使用 `wiki +node-get --as user` 验证新节点的 parent 为 `LVtIwNHJ9it0Rkk3On9cb6GgnSd`。若父节点错误，移动到固定父节点后再次验证。未完成全部覆盖和父节点验证前，不要宣布完成。

## 交付

报告新文档链接、原文链接，以及任何图片或内容降级说明。只有在完整性检查和父节点检查都通过后，才报告归档完成。
