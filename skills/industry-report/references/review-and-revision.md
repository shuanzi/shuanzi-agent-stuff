# 审阅与修改

## 确定本轮修改权

| 当前授权 | 适当行动 |
| --- | --- |
| 只审阅、只提方案 | 核实问题，给意见或拟文，保留原文件 |
| 只改指定段落 | 读必要上下文，只写指定区域；范围外问题单列 |
| 局部整改 | 完成确认问题及直接受影响的衔接；可在范围内重排、补解释，不能退化为替词 |
| 整篇重构 | 可调整论点、章节与案例位置；保护研究目标，追踪引用及结论变化 |

按当前授权推进，不从旧任务继承审批停点；已确认内容不因统一风格顺手重写。指定段落有事实疑点应核实或限定，不为保留原话继续传播错误。修复必须超出权限时，先完成范围内独立工作，再明确所需扩展。

## 诊断与处方分开

重要意见记录“原文位置—本段应回答的问题—实际障碍或错误—依据—建议改法—处理结果”。短任务可用一两段，无须强制建表。

先读原段、相邻段、标题和依据，区分事实错误、推论过度、结构缺口、表达障碍、风格偏好及审阅者读取不足。再判断改法能否解决问题，会不会越权、增加断言或丢失条件。

| 问题判断 | 改法判断 | 处理 |
| --- | --- | --- |
| 成立 | 合适 | 按授权修改并核对结果 |
| 成立 | 不合适 | 保留问题，提出替代方案或有限结论 |
| 尚不能判定 | 任意 | 补必要原文或证据，标清待确认点 |
| 不成立或仅偏好 | 不必执行 | 说明原文为何已足够，不凑整改项 |

不能因建议要求无依据的量化矩阵，就忽略“现有路径比较抽象”的真缺口；不能因此前通过拒绝具体反例。多模型相同意见只提示核查优先级。

## 看内容如何工作

- **论证职责**：本节回答什么？每段交代背景、解释机制、提供证据、比较路径还是提出建议？缺哪一步，哪些段落反复做同一件事？
- **因果承接**：为何从这段走到下一段？只加“因此、同时”不能修复逻辑，更不能把时间相邻写成因果。
- **案例增量**：再次出现是否增加分工、成本、条件等分析？介绍、机制解释、比较可合理呼应；同一介绍与结论反复出现则合并或回指。
- **建议依据**：解决前文哪个问题？谁有能力和权限做？缺条件时如何限定？技术接口不直接证明产业规模或政策成效。
- **正文位置**：判断所需限制留在相关论述；读取过程、配置和交付历史仅在有用途的附件或工作记录中保留，不强制所有报告建立核验附件。

## 自然表达与语义保护

遇到压缩的抽象说法，先用日常语言复述原意，再恢复必要术语。明确谁处理什么对象、为何需要另一方配合、改变了什么。不要机械补齐四个句子成分，也不要把所有段落改成主体轮流做事的排比。

首次出现的对象交代身份，概念解释与当前判断有关的用途。需要图时画依赖、分支或比较，标明归纳性质；箭头不能把可选路径画成必经流程。

改写前后重点对照：

- 主体、对象和责任是否转移或扩大；
- “可以／应当”“可能／已经”“部分／全部”“未找到／不存在”的力度是否改变；
- 并行是否变成固定顺序，相关是否变成因果；
- 版本、预览、设备、负载、统计对象等条件是否保留；
- 引用迁移后是否仍支持附近的新句子。

数字与编号不变只证明部分内容未变，语义保护仍须阅读。需要示范时读[真实改写例](examples.md)。

## 校准、复查与结束

样稿选最不确定的“事实到分析”片段，不只展示流畅背景。迁移其判断标准，不能推定其他章节自动合格。

长报告、重要判断或多次自改仍有障碍时，可安排独立阅读。提供实际版本、目标读者和任务；找盲点时先不给旧通过结论，意见形成后再核历史。仅检查修改影响时，差异和相邻语境足够，不必每次重审全篇。

约定实质问题处理后，核实际差异、受影响依据和衔接，确认没有新引入的事实、引用、语义问题，即交付并说明限制。风格偏好不触发无限复审；新证据、明确问题或用户反馈可重开相应范围。连续调整仍失败时，回到研究问题和段落职责，不继续累积禁词或替换规则。
