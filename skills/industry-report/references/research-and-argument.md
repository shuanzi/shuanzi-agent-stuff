# 研究与论证

用于新选题、论证不足的报告或已获授权的整篇重构。局部任务只取相关部分。

## 从共同困难到可回答的问题

用一小段或简表明确：读者将据此判断什么；哪些参与者遇到什么共同困难；现有安排为何不足；本报告准备解释什么；证据覆盖哪些地区、时期、场景和主体。时间、篇幅、格式服从本次要求。

- 选题是否涉及值得解释的供需、分工、依赖、激励或公共能力，而不只是产品的新功能？
- 是否存在有意义的路径差别或矛盾，例如通用支持与专用优化、共享建设与持续维护、采用成本与退出成本？差别来自材料，不能为“平衡”虚构反方。
- 材料是否足以回答题目？证据不足时可缩题、改成机制研究、补查或暂缓，不能靠堆新闻和拉长背景补足。
- 与相邻专题的判断职责有什么区别？同一案例可复用，分析任务应不同。

可用“某类参与者在某项变化下，如何处理某个共同问题”帮助立题。厂商或产品也可成为研究对象，但不能把个案结论冒充行业结论。

## 证据边界和来源

关键事实就近引用能直接支持它的原始材料。聚合资料可发现线索；技术事实优先原始文档、版本记录、规范、论文或代码。政策研究核对发文机关、文件性质、适用对象、生效阶段及原始文本，区分征求意见、规划目标、实施规则和实际执行。机构公告能证明其公布或自述了什么，不能单独证明采用效果或普遍成效。

按规模选择轻量笔记或来源表，至少能追溯：

| 信息 | 用途 |
| --- | --- |
| 论述与定位 | 支撑哪句话、表或判断 |
| 来源与身份 | 发布者、标题、原始链接或本地出处 |
| 日期 | 事件日、发布日期、访问日；未知保留未知 |
| 版本与范围 | 版本、地区、样本、设备、任务或统计口径 |
| 实际证据 | 读到的原句、数据或实现，以及能支持到的程度 |
| 缺口 | 未读、仅摘录、冲突或无法核实之处 |

动态网页与固定版本按论述用途选择：机制解释可用较早但仍适用的固定规范；声称研究窗口内的当前状态，就核对窗口内相关更新。不要因“有新版”机械换来源，也不要用旧版冻结为理由忽略改变结论的新进展。

访问日期不是发布日期，页脚年份不是事件年份，事后访问不自动扩展研究窗口。网页变化时保存准确版本、提交号或必要原文快照。读取快照与当次在线访问分别记录，校验和只能证明字节一致，不能证明事实成立。

来源冲突时对照定义、时期、条件和主体，不投票选多数。证据只能支持“未找到充分材料”时，不写成“行业没有这种能力”。统计、性能或政策成效要保留分母、样本、时间、单位及可比条件；不同条件不能直接推出排名或因果。同源转载不能算多份独立证据。

## 让结构承载推理

大纲为每章写“问题—暂定判断—所需证据—与前后章的关系”；暂定判断可以待证。常见顺序是“为什么关注→参与者与变化→机制与矛盾→路径比较→建议”，但不强制章数，也不为统一形式拆开连贯分析。

诊断三种断裂：

- **并排放材料**：段落都准确，却不知为何相邻。补读者缺少的共同问题、依赖或转折，必要时重排。
- **案例直接跳建议**：补机制、影响及可推广条件，才从个案进入判断。
- **标题正文错位**：标题讨论协同，正文却讲作者如何分类资料。让正文回答标题，把内部记录移位。

章首用内容衔接，不必重复目录式预告。摘要压缩研究问题、主要判断与实际含义；结语收束已论证认识和待追踪问题，不再复述全篇。

## 案例、产业判断与建议

案例围绕“做法—作用机制—各方收益与负担—成立条件—启示”展开，视证据取舍，不逐段套句。区分案例事实和研究者解释；未报告成本不等于没有成本，潜在收益不等于收益已经发生。

从技术事实追问：谁多做或少做了什么工作？成本、风险或维护责任转移给谁？共用部分可复用到哪里，专用部分仍由谁负责？采用方还需什么条件？什么证据会推翻或缩小当前判断？

建议接回前文问题，说明适当主体、行动、预期解决的困难及关键条件。必要时比较路径的收益、资源负担、可逆性和观察信号；政策建议还要检查职责权限、激励、资源约束及对不同主体的影响。资料不足可提出试点或进一步研究，不编造预算、效果或“已形成机制”。

不要求每篇产生量化评分、政策工具矩阵或试点方案。例子、归纳流程和假设演算须让读者知道其性质，不能当成真实实施结果。
