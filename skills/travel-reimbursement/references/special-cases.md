# 专项、市内打车与出国境

本页是按场景整理的执行说明。完整正文和原始附件均见[离线资料索引](sources.md)，按实际场景读取对应部分。

## R、T、GZ 项目（S1、S2、S3）

S3 的 R 专项专页本次为空；**不能写成已掌握 R 专项报销制度**。S1 中明确的 R 和 T（GZ）事由示例可用：

- 会议：“某人申请赴某地（起止日期）针对某任务参加某会议”，附会议通知。
- 一般交流：“某人申请赴某地某单位（起止日期）针对某任务进行学术交流/技术交流/咨询某事项”。

从用户实际任务与活动写具体事由，不杜撰课题相关性。R 是否有额外材料、费用范围、专项审核人需补充依据。GZ 延期需报备、在报销单写原因及组长签字；不同核算账号分别申请。上述规则不意味着 R、T、GZ 是同一经费类别。

## 市内因公打车（S5）

走普通报销单和内部打车信息汇总，不套国内差旅 100/80 补助。原文要求组秘每月 20 日前将当前打车费用制作报销交财务；用户只整理时记录本月截止日，不自动建立提醒或发送。

汇总字段为：出行人、报销金额、出行事由、材料压缩包（行程单＋发票）。费用明细还需日期、起终点及支付事实用于判断以下边界：

| 实际路径 | 源文可报范围 |
|---|---|
| 家→会场→公司 | 只报会场→公司单程 |
| 公司→会场→家 | 只报公司→会场单程 |
| 家→会场→家（开完会约 17 时散会回家） | 源文案例不报打车费，特殊情况补合理说明并待财务确认 |
| 公司↔因公地点 | 核对因公事实及票据后按实际符合条件的行程整理 |
| 去机场/火车站 | 只能放在相关差旅费报销，不能作为独立市内交通费报销 |

- 线上快车：电子发票＋行程单，制作标注副本写明外出人和事由，保留原 PDF；电子包加普通报销单，纸质单按原流程签字。原文“强烈推荐”不写成唯一允许方式。
- 线下出租车：清晰的单张发票，贴 A4、扫描；原文后续是组秘 ARP 手动添加“出租车票”，财务出明细表后填表人和外出人分别签字，再由财务上传。未实际办理就标待处理。
- 多人使用商务车须必要性说明，不能只凭车型自动判不可报或一概允许。
- 使用包内[普通报销单原模板](../assets/普通报销单.docx)，可先读[字段文本](attachments/普通报销单-字段.md)。完整来源见 [S5 市内出差打车报销](policies/S5-市内出差打车报销.md)。不能把国内差旅单标为市内交通报销单。

## 出国（境）（S4）

这是外事资料准备流程，**不用国内差旅表生成脚本**。完整来源见 [S4 出国境流程](policies/S4-出国境流程.md)。包内已保存[外事流程通知](attachments/外事流程通知-OCR.md)、[事前公示信息表](../assets/外事事前公示信息表.docx)、[预算审批意见表正文](policies/S6-因公临时出国任务和预算审批意见表.md)及[原表](../assets/因公临时出国任务和预算审批意见表.docx)。预算审批意见表不是报销核销表；《临时出国人员开支核销表》及其中的《国外费用报销单》仍未取得，不用其他表代替。

### 事前与日期

- ARP 两条流程：先国际合作模块走完、允许办理出境手续，再在“事前申请→出差申请→业务事项”选择外事出访/国际差旅/相应学生博士后事项。两者影响不同，不能用一个审批替代另一个。
- 邀请函核对电子签、邀请人姓名/电话/地址、被邀请人、活动起止和具体城市，职务建议有。不得为满足材料要求补造签名。
- 按邀请议程、航班、转机、时差核对实际出入境和拟出访日期。原文“一般 6–10 天”是描述，不当作固定额度；负责人年度天数需相关部门确认，不能用国内小于 7 天规则裁剪境外行程。
- 费用来源按邀请函及财务确认的核算账号；外币限额先读[地区索引与查询规则](overseas-rates-index.md)，按国家/地区、实际城市、备注和适用日期查总表及 2017 住宿调整 CSV。两表已对照原 PDF 逐行校订，可按稳定 ID 和页码追溯；住宿、伙食、公杂费分别保留币种，不按国家整体覆盖。遇原文冲突或范围未明时回读相应 PDF 页并列具体待确认点。两份文件是源文附带版本，未额外认定其在所有出差时点均为最新有效制度。

### 资料清单

以下均交电子版；纸质仅交确有原件的部分，扫描/复印件不重复要求纸质：

1. 出境审批表。
2. 会议、论坛等邀请函。
3. 登机牌及行程单。
4. 银行卡付款截图，按费用归类，图片命名“某费用支付截图”。
5. 采用汇率的证明与说明 Word，附中国银行牌价截图，圈出选用项、日期和时刻、币种、单位与选择理由。
6. 签证和签证费支付截图；已在支付材料中则引用同文件，不重复复制。
7. 临时出国人员开支核销表，核对后打印，由出国人签字。
8. 国外费用报销单（原文称包含在核销表中，拿到模板再核对）。
9. 护照首页、签证页、出境和入境签章页、国内出入境证明；如港澳缺签章日期，需国家移民管理局出入境记录 PDF。
10. 电子保单及保险费发票；保险资格表述有歧义，列待确认，不能全额默认报。

涉及 SM 投稿，原文要求备注稿件名、作者和时间，不上传投稿审批表。只处理用户提供且当前任务必要的材料。

### 汇率与金额

- S4 要求出差期间中国银行**现汇卖出价**；选用哪一天/哪一刻要标理由。原文示例最高汇率不构成一律择高的授权。
- 报价单位必须核对，如牌价按每 100 外币表示，换算须除 100；用户已有实际人民币入账与汇率试算不得双算。该换算校验是计算要求，不是另加单位报销政策。
- 汇率及核销表金额按原文要求保留两位小数；核销表明确“舍掉、不进位”，用 `Decimal.quantize(Decimal('0.01'), rounding=ROUND_DOWN)`，不用 Python 默认 `round()`。原始报价/原币金额另留核对记录，注明采用两位的阶段；对具体舍尾顺序仍影响金额时待财务确认。
- 外事费如采集费、经确认可报的保险费计杂费。汇总页只备注汇率，其他说明放后两页/附件；不在汇总页塞入全部编辑说明。
- 报销包命名沿用申请主题，例如“某人申请某地外事差旅（申请起止日期）参加某会议”；表内与出入境证据填实际日期。
